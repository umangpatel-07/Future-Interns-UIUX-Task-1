IMPORT INTO FIGMA
1. Unzip this package.
2. In Figma, create a new Design file.
3. Drag each SVG onto the canvas, or use File > Place image.
4. Right-click an imported SVG and choose Ungroup to edit vector shapes/text.
5. Check font rendering and spacing after import.

NOTE
This package contains Figma-importable editable SVG source, not a native .fig file.
The task asks for a public GitHub repository: create a public repository and upload
the six SVGs, rationale PDF, and this README. Do not publish fictional details
as real clinic information.
